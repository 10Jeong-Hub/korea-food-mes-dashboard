# (주)코리아식품 생산 작업 기록 — GitHub Pages 배포

원료육 출고 → 세척 → 포장을 현장 태블릿·PC에서 입력하고, 작업일지 · 생산일지 · 해당일 기록 · 제품 1차 수량 확인용을 자동으로 생성하는 PoC(개념 검증용) 웹앱입니다.

---

## 🚀 배포 방법 (약 5분 소요)

1. **GitHub 로그인** → 오른쪽 위 `+` → **New repository**
2. **Repository name** 설정 (예: `kf-worklog`) → **Public** 선택 → **Create repository**
3. 새 저장소 화면에서 **uploading an existing file** 클릭
4. 프로젝트 폴더의 전체 파일 드래그 앤 드롭  
   *(index.html, manifest.webmanifest, icon-*.png, apple-touch-icon.png, favicon.png, .nojekyll, README.md)*  
   - `.nojekyll`처럼 숨김 파일이 보이지 않아도 정상 동작합니다.
5. 아래 **Commit changes** 클릭
6. 저장소 **Settings** → **Pages** → **Source: Deploy from a branch** → **Branch: main / /(root)** 선택 후 **Save**
7. 1~2분 뒤 상단에 접속 주소가 생성됩니다: `https://<GitHub아이디>.github.io/kf-worklog/`

## ⚠️ PoC 환경 참고 사항

* **클라이언트 로컬 저장 방식**:  
  본 데모 버전은 별도 외부 DB 서버 없이 각 기기(브라우저 LocalStorage)에만 독립 저장됩니다.  
  따라서 입력한 기기에서만 데이터가 확인되며, 향후 본 프로젝트 구축 시 중앙 데이터베이스(MES DB/클라우드 서버)와 연동하여 다중 기기 실시간 동기화를 지원할 예정입니다.
* **데이터 백업 권장**:  
  브라우저 캐시 및 사이트 데이터를 초기화하면 로컬 기록이 삭제될 수 있으므로, 테스트 데이터는 **[기록 → 엑셀로 받기]** 기능을 통해 백업하시는 것을 권장합니다.
* **접근 보안**:  
  본 배포 사이트는 PoC 검토용으로 검색엔진 크롤링 방지 메타태그가 적용되어 있으나, URL 주소를 알고 있는 인원에 한해 테스트 접근이 가능합니다.
* **테스트 데이터 리셋**:  
  시연 후 초기 상태로 되돌리려면 **[설정 → 기록 초기화 → 전체 기록 지우기]**를 진행하시면 됩니다.
